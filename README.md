# Auto Technical Atlas

Personal offline Android technical atlas for vehicles.

## Main concept

The application is data-driven.

Each exact vehicle configuration can have its own technical dataset:

Manufacturer
→ Model
→ Generation
→ Year
→ Modification
→ Engine
→ Transmission
→ Drivetrain

## Technical systems

- Engine
- Transmission
- Electrical
- ECU
- CAN
- LIN
- Cooling
- Fuel
- Lubrication
- Intake
- Exhaust
- Vacuum
- Brakes
- ABS / DSC
- Suspension
- Steering
- HVAC
- Body
- Interior
- Fuse boxes
- Relays
- Sensors
- Connectors

## Viewer

The future technical viewer will support:

- rotation
- zoom
- technical line rendering
- layers
- component selection
- system isolation
- exploded view
- connection tracing
- component search

## Data

Vehicle data will be stored separately from application logic.

This allows new vehicles to be added without rewriting the application.
